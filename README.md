# 온결 커머스 웹사이트 시안

민감성 피부를 위한 저자극 스킨케어 브랜드 **온결(ONGYEOL)**의 반응형 커머스 화면 시안입니다. 기존 작업 파일을 보존하기 위해 별도 폴더에 구성했습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 별도 빌드나 설치 과정은 없습니다. Google Fonts는 네트워크가 연결되어 있을 때 적용되며, 연결되지 않아도 시스템 글꼴로 표시됩니다.

## 화면

- `index.html`: 메인, 피부 고민 탐색, 베스트 상품
- `search.html`: 카테고리·키워드 검색 결과, 추천순·가격순 정렬
- `product.html`: 상품 정보, 옵션 선택, 상세 설명, 관련 상품
- `cart.html`: 담은 상품·수량·상품 금액 확인 및 수량 변경·삭제
- `checkout.html`: 배송 정보 입력·확인 시안
- `recent.html`: 최근 열어 본 상품 목록
- `company.html`: 온결 브랜드 소개와 사업자 정보
- `login.html`: 로그인 폼과 입력 오류 안내
- `signup.html`: 가입 정보, 비밀번호 확인, 필수·선택 동의
- `styles.css`: 공통 디자인 시스템과 반응형 레이아웃
- `script.js`: 상품 데이터, 화면 렌더링, 검색·정렬, 장바구니 저장·계산, 폼 검증
- `order.js`: 장바구니에서 주문 정보 화면으로 이동, 배송 정보 검증
- `product-page.js` / `recent.js`: 최근 본 상품 기록 및 상품 상세 탭 전환
- `share.js`: Instagram 링크 복사, X·Facebook·네이버 블로그 공유, Kakao SDK 공유
- `footer.js`: 참고 이미지 구성을 반영한 공통 회사 정보 footer

## 기획 기준

- 주요 고객: 민감성 피부 제품을 찾는 20~30대
- 상품군: 저자극 스킨케어
- 차별점: 피부 고민과 성분을 확인하며 비교할 수 있는 탐색
- 브랜드 톤: 차분하고 신뢰감 있는 녹색·뉴트럴 팔레트
- 화면 기준 너비: 모바일 390px, 태블릿 768px, PC 1440px
- 샘플 상품 8개: 짧고 긴 상품명, 할인·비할인, 다양한 카테고리 포함

## 시안 범위

검색, 카테고리 이동, 상품 상세 진입, 가격 정렬, 장바구니 개수 표시, 폼 입력 검증은 브라우저 안에서 동작합니다. 계정 생성·인증, 서버 저장, 실제 재고 확인, 결제는 연결하지 않았습니다. 상품, 가격, 리뷰, 배송, 성분 등은 모두 화면 확인을 위한 가상 데이터입니다. 실제 판매 전에 정확한 상품 정보와 정책으로 교체해야 합니다.


## Kakao Talk 공유 연결

share.js의 KAKAO_JAVASCRIPT_KEY에 Kakao Developers 앱의 JavaScript 키를 설정하세요. Kakao Developers에서 사이트의 JavaScript SDK 도메인과 공유 링크 도메인을 등록해야 합니다. file://로 직접 연 페이지에서는 공유가 제한되므로 로컬 서버나 배포된 HTTP(S) 도메인에서 확인하세요. 앱 키가 비어 있으면 카카오톡 버튼은 링크 복사 안내를 표시합니다.
